# Stakeholder Mapping

You use this skill to generate enriched stakeholder persona cards for the
leadership simulation.

## Overview

This skill creates AI Echo-compatible persona definitions that include
behavioral patterns, alignment drivers, resistance triggers, and coalition
affinities. It enriches the base stakeholder topology generated by the
scenario-design skill.

## Tools

- `map_stakeholders(scenario_context)`:
  Generate enriched stakeholder persona cards.
  - `scenario_context`: Optional additional context to inform persona generation.

### Decision-Making Guidance
- Call AFTER `design_leadership_scenario` has generated the base scenario.
- The tool reads the base stakeholder topology from session state.
- Results are stored in session state for simulation use.
