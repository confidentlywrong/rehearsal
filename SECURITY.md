# Security Policy

## Reporting a Vulnerability

If you find a security issue, please report it privately through the Report a vulnerability button on the Security tab at [github.com/confidentlywrong/rehearsal/security/advisories/new](https://github.com/confidentlywrong/rehearsal/security/advisories/new). Please do not open a public issue for a live vulnerability.

We will reply within five working days.

### What to Include

* A description of the vulnerability and its potential impact.
* Steps to reproduce the issue or a minimal proof of concept.
* The affected component, such as the Go gateway, Python ADK agents, Angular frontend or Terraform infrastructure.
* Any suggested mitigation or fix if you have one.

Please do not include real names, company names or confidential organizational data in your report.
