# Security Policy

## Reporting a Vulnerability

If you find a security issue, please report it privately using GitHub's **"Report a vulnerability"** button on the **Security** tab of this repository ([github.com/confidentlywrong/rehearsal/security/advisories/new](https://github.com/confidentlywrong/rehearsal/security/advisories/new)), rather than opening a public issue.

**We will reply within 5 working days.**

### What to Include

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue (or a minimal proof-of-concept)
- The affected component(s) (e.g., Go gateway, Python ADK agent, Angular frontend, or Terraform infrastructure)
- Any suggested mitigation or fix, if you have one

Please do not include real names, company names, or confidential organizational data in your report.
